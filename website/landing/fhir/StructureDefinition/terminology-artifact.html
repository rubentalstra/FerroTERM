Terminology artifact

The built index a served code system version was read from: the artifact directory's own name and the release identifier the offline build recorded in its manifest. The element has the same path on R4, R4B, R5 and R6, and the server writes the extension on every version it serves.

Canonical: https://ferroterm.eu/fhir/StructureDefinition/terminology-artifact

Context: TerminologyCapabilities.codeSystem.version

Definition: terminology-artifact.json, a StructureDefinition in the FHIR R4B shape.

ElementTypeCardinalityMeaning
namestring0..1The artifact directory's own name, without the directories above it. Absent when the path has no final component.
releasestring1..1The release identifier the offline build wrote into the artifact's manifest: the release date for SNOMED CT, the release version for the other systems.
