Operation level

One level at which the server answers an operation: system, type or instance, as the served version's own OperationDefinition declares it. The extension repeats once per level. The element has the same path on R4, R4B, R5 and R6, and the server writes the extension on every version it serves.

Canonical: https://ferroterm.eu/fhir/StructureDefinition/operation-level

Context: CapabilityStatement.rest.resource.operation

Definition: operation-level.json, a StructureDefinition in the FHIR R4B shape.

(the extension itself)code0..3One level at which the server answers this operation, repeated once per level: system, type (the resource type) or instance (one resource by id).
