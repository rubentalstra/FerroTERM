Implicit value set form

One implicit value set form a served code system version resolves: the URL template and what its placeholders take. The extension repeats once per form. The element has the same path on R4, R4B, R5 and R6, and the server writes the extension on every version it serves.

Canonical: https://ferroterm.eu/fhir/StructureDefinition/implicit-value-set

Context: TerminologyCapabilities.codeSystem.version

Definition: implicit-value-set.json, a StructureDefinition in the FHIR R4B shape.

ElementTypeCardinalityMeaning
patternstring1..1The value set URL template, spelled as the code system's page spells it, with each placeholder in square brackets, for example http://snomed.info/sct?fhir_vs=isa/[sctid].
argumentcode1..1What the placeholders take: none when the pattern is the URL as it stands, code when the one placeholder takes a code of the system, expression when the placeholders take free text such as an ECL expression or a UCUM unit.
